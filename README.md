# VSD-RTL — RTL Design and Synthesis Workshop

## Overview

This repository documents my hands-on learning and progress during the **VSD RTL Design and Synthesis Workshop**.

The workshop covers Verilog RTL design, simulation, synthesis, optimization, and gate-level verification using open-source EDA tools and the SKY130 standard cell library.

Each day's work is organized into a separate folder containing documentation, relevant RTL files, simulation results, synthesis outputs, and screenshots.

## Key Learning Areas

- RTL design using Verilog HDL
- Testbench development and RTL simulation
- Waveform analysis using GTKWave
- Synthesis using Yosys
- Understanding timing libraries
- Hierarchical and flat synthesis
- Combinational and sequential logic optimization
- Latch inference and coding practices
- Gate-Level Simulation (GLS)
- Blocking and non-blocking assignments
- RTL and synthesis simulation mismatches
- Hardware inference from Verilog constructs

## Learning Approach

The workshop documentation includes:

- Practical experiments and RTL implementations
- Simulation commands and waveform analysis
- Synthesis commands and generated schematics
- Screenshots of tool outputs
- Notes on concepts, errors, and observations

## Purpose

This repository serves as a record of my practical learning and experiments in RTL design and synthesis.

It is intended to strengthen my understanding of digital design, Verilog coding, synthesis, and the fundamentals of VLSI design.
